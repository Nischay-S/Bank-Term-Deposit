Try the model

Change a customer’s details and watch the model’s estimate of their chance of subscribing to a term deposit move. Everything runs in your browser; nothing is sent anywhere.

Pre-call model. It only uses what a bank knows before dialling (no call duration). It was trained on past contacts from a Portuguese bank (2008 to 2010), so treat the output as a probabilistic estimate for exploring how the model behaves, not as advice about a real person.

Customers at or above this probability are classed as likely subscribers. The default was chosen on validation data to favour finding subscribers (an assumption about costs).

What moved the estimate

One-at-a-time what-if: each input is swapped for a typical customer’s value and the change in the estimate is shown. Teal raised it, amber lowered it. This is a simple what-if view, not SHAP.

    What you are looking at

    • The model is a gradient-boosting classifier ( small decision trees). Its trees were exported from the trained Python model and are evaluated here in JavaScript; the output matches the Python model.
    • On held-out historical data it ranked customers well above chance (ROC-AUC , PR-AUC ), but only about of the customers it flagged actually subscribed at the default threshold.
    • These are associations in historical data. Changing one input here shows how the model reacts, not what would make a real customer subscribe.
    • The data is ordered by date and was split at random for the main results, so scores are optimistic for a future campaign. See the project site for the time-ordered check and other limitations.
